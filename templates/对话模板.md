# 对话数据格式模板

本文档定义了AI思维克隆器所需的对话数据格式规范。

## 数据格式

### JSON格式（推荐）

```json
[
  {
    "id": "001",
    "timestamp": "2024-01-15T10:30:00",
    "role": "user",
    "content": "你怎么看待人工智能对就业的影响？",
    "context": {
      "topic": "科技",
      "emotion": "好奇"
    }
  },
  {
    "id": "002",
    "timestamp": "2024-01-15T10:30:15",
    "role": "assistant",
    "content": "这个问题很值得深思。我认为AI对就业的影响是双刃剑。一方面，重复性、规律性的工作确实会被取代，比如数据录入、基础翻译这些。但另一方面，AI也会创造新的就业机会，比如AI训练师、提示词工程师等。关键在于我们如何适应这种变化。",
    "context": {
      "topic": "科技",
      "style_tags": ["平衡视角", "举例说明"]
    }
  }
]
```

### 问答对格式

适用于已整理的问答数据：

```json
[
  {
    "question": "你如何评价远程办公？",
    "answer": "远程办公改变了我们的工作方式。优点很明显：省去了通勤时间，工作安排更灵活，可以更好地平衡工作和生活。但缺点也不容忽视：缺乏面对面交流，团队协作效率可能下降，工作边界变得模糊。我认为未来会是混合办公模式，取两者之长。"
  }
]
```

## 字段说明

### 必填字段

| 字段 | 类型 | 说明 |
|------|------|------|
| content | string | 对话内容文本 |
| role | string | 角色：user/assistant |

### 可选字段

| 字段 | 类型 | 说明 |
|------|------|------|
| id | string | 唯一标识符 |
| timestamp | string | ISO 8601格式时间戳 |
| question | string | 问题文本（问答对格式） |
| answer | string | 回答文本（问答对格式） |
| context | object | 上下文信息 |
| context.topic | string | 话题分类 |
| context.emotion | string | 情绪标签 |
| context.style_tags | array | 风格标签 |

## 数据质量要求

### 数量要求

- 最少样本数：100条对话
- 建议样本数：500条以上
- 理想样本数：2000条以上

### 质量要求

1. **真实性**：对话内容应反映真实的思维方式和表达习惯
2. **多样性**：覆盖不同话题、情绪状态、对话场景
3. **完整性**：对话片段应完整，避免过短或残缺的内容
4. **代表性**：选择最能体现个人风格的对话内容

## 示例数据

### 示例1：专业讨论型

```json
{
  "question": "你认为什么样的产品经理是好产品经理？",
  "answer": "好产品经理需要具备三个核心能力。第一，用户洞察力，要真正理解用户的痛点，而不是想当然地替用户做决定。第二，数据敏感度，能从数据中发现问题，验证假设，而不是靠拍脑袋。第三，沟通协调能力，产品经理需要连接技术、设计、运营多个团队，没有好的沟通能力，再好的想法也落地不了。"
}
```

### 示例2：情感表达型

```json
{
  "question": "最近工作压力很大，怎么调节？",
  "answer": "压力大的时候，先别逼自己硬扛。我建议你试试这几个方法：一是运动，出一身汗，脑子会清醒很多；二是找人倾诉，有时候说出来压力就减轻一半了；三是给自己设定边界，工作再重要也不能透支健康。记住，状态不好的时候，允许自己慢下来。"
}
```

### 示例3：分析推理型

```json
{
  "question": "电商行业未来会怎样发展？",
  "answer": "电商行业正在经历三个层面的变革。首先是渠道层面，从传统电商向内容电商转型，直播带货只是开始，未来会有更多沉浸式购物体验。其次是供应链层面，C2M模式会让反向定制成为主流，库存压力会大大降低。最后是技术层面，AI会重塑整个购物流程，从推荐到客服再到物流，都会更智能化。传统电商平台如果不转型，生存空间会越来越窄。"
}
```

## 数据预处理建议

1. **去重**：删除重复的对话内容
2. **清洗**：去除无效字符、广告链接等
3. **分类**：按话题或场景对对话进行分类
4. **标注**：为关键对话添加风格标签
5. **脱敏**：移除个人隐私信息

## 注意事项

- 确保数据来源合法合规
- 敏感信息需进行脱敏处理
- 保持数据的时效性，定期更新
- 不同场景的对话可以分别建立数据集
