# 写作风格模拟模板

## 模板说明

使用本模板让 AI 模仿特定写作风格进行内容生成。

### 模板参数

```
{风格}: 目标写作风格名称（如"村上春树风格"、"科技报道风格"）
{语气}: 正式/轻松/幽默/严肃
{长度}: 简短(<500字) / 中等(500-2000字) / 长篇(2000+字)
{受众}: 目标读者群体描述
```

### 提示词结构

```
请以{风格}的风格写一篇关于{主题}的文章。

语气要求：{语气}
目标长度：{长度}
目标受众：{受众}

具体要求：
1. [具体要求1]
2. [具体要求2]

参考该风格的核心特点：
- [特点1]
- [特点2]
- [特点3]
```

### 示例：模仿乔布斯风格

```
请以乔布斯的风格写一篇关于AI未来的短文。

语气要求：简洁有力，富有激情
目标长度：中等（约1000字）
目标受众：科技爱好者

具体内容：
- 回望历史，AI的发展经历了三次浪潮
- 当前AI面临的真正瓶颈
- 未来十年AI将如何改变生活

参考乔布斯风格特点：
- 短句为主，多用"and"连接
- 使用"incredible", "revolutionary"等强力形容词
- 喜欢三分法论述
- 以简洁有力的结论收尾
```
