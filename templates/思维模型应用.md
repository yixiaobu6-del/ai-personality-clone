# 思维模型应用模板

## 模板说明

使用本模板将特定思维模型应用到问题分析中。

### 适用场景

- 商业决策分析
- 问题根源分析
- 战略规划制定
- 风险评估与管理

### 模板结构

```
## 待分析问题

{问题描述}

## 选用的思维模型

{模型名称}：{模型简要说明}

## 应用过程

### 第一步：{步骤一名称}
{应用该模型的第一步分析}

### 第二步：{步骤二名称}
{应用该模型的第二步分析}

### 第三步：{步骤三名称}
{应用该模型的第三步分析}

## 结论与行动建议

基于以上分析，得出的核心结论和可执行的行动方案。
```

### 可用思维模型

| 模型 | 适用场景 | 核心问题 |
|------|----------|----------|
| 第一性原理 | 创新突破 | "这件事的本质是什么？" |
| 第二层思维 | 投资决策 | "大家的共识是什么？我是否同意？" |
| 奥卡姆剃刀 | 问题简化 | "最简单的解释是什么？" |
| 帕累托法则 | 效率提升 | "哪20%的投入带来80%的产出？" |
| 复利思维 | 长期规划 | "哪些事有长期复利效应？" |
| 反脆弱 | 风险设计 | "如何从波动中受益？" |

### 示例

```
## 待分析问题
是否应该从大厂辞职做独立开发者？

## 选用的思维模型
第一性原理 + 反脆弱

## 应用过程

### 第一性原理分析
1. 工作本质是什么？是安全感的来源（薪水+福利）与能力的交换
2. 独立开发的本质是什么？直接面向市场创造价值
3. 终极目标是什么？时间自由 + 收入无上限

### 反脆弱分析
1. 留在公司：稳定但脆弱（裁员风险）
2. 独立开发：波动大但有反脆弱性（多个收入来源）
...
```
