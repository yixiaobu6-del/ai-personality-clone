# 更多结构化格式模板

## JSON 输出模板

用于需要结构化输出的场景，如数据处理、API响应等。

```json
{
  "analysis": {
    "topic": "问题主题",
    "method": "分析方法",
    "timestamp": "分析时间"
  },
  "findings": [
    {
      "key": "关键发现1",
      "evidence": "支持证据",
      "confidence": 0.85
    }
  ],
  "recommendations": [
    {
      "action": "建议行动",
      "priority": "high/medium/low",
      "expected_impact": "预期效果"
    }
  ]
}
```

## CSV 输出模板

```csv
维度,评分,说明
技术可行性,8/10,技术方案成熟
市场前景,7/10,目标市场增长中
团队匹配,6/10,需补充AI方向人才
风险等级,低,主要风险可控
```

## Markdown 报告模板

```markdown
# 分析报告：{标题}

## 一、背景
{问题背景}

## 二、分析过程
{分析方法和步骤}

## 三、关键发现
1. {发现一}
2. {发现二}
3. {发现三}

## 四、风险与挑战
- {风险一}：{应对方案}
- {风险二}：{应对方案}

## 五、行动建议
| 优先级 | 行动项 | 负责人 | 时间线 |
|--------|--------|--------|--------|
| P0 | {核心行动} | {人} | {时间} |
| P1 | {重要行动} | {人} | {时间} |

## 六、附录
{参考资料和补充数据}
```
