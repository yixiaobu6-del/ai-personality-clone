# AI 思维克隆器

[![HTML](https://img.shields.io/badge/HTML-standalone-orange)]()
[![Tailwind CSS](https://img.shields.io/badge/Tailwind-CSS-blue)]()

AI 人格克隆配置工具，支持多种人格类型。

## 功能

- **15 种人格**：乔布斯、塔勒布、马斯克等
- **多配置管理**：同时管理多份克隆配置
- **配置共享**：复制代码 + 导入导出
- **对话测试**：实时体验不同人格

## 使用

打开 `clone_config.html` 即可使用。
